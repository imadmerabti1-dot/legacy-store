# Publish LEGACY.STORE

## 1. Upload to GitHub

Create a new GitHub repository, for example `legacy-store`.

Upload the contents of this folder directly into the repository root:

`index.html`, `styles.css`, `app.js`, `vercel.json`, `assets/`, and the documentation files.

Do not upload the parent `SHOE STORE` folder around it; `index.html` must be at the repository root.

## 2. Deploy with Vercel

1. Open Vercel and choose **New Project**.
2. Import the `legacy-store` GitHub repository.
3. Keep Framework Preset as **Other**.
4. Keep the Root Directory as `.`.
5. Leave Build Command and Output Directory empty.
6. Click **Deploy**.

Vercel will give you a public URL and automatically redeploy the site after future pushes to GitHub.
